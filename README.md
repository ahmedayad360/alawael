# نسخة التجربة على GitHub Pages

| الملف | الوصف |
|---|---|
| `index.html` | صفحة اختيار (لوحة التحكم / التطبيق) |
| `dashboard.html` | لوحة التحكم — ملف واحد مكتفٍ بذاته |
| `app.html` | تطبيق الجوال — ملف واحد مكتفٍ بذاته |
| `.nojekyll` | يمنع معالجة Jekyll على GitHub Pages |
| `publish.sh` | سكربت رفع سريع |

**التفعيل:** Settings → Pages → Deploy from a branch → main → / (root) → Save.
**الرابط:** `https://USERNAME.github.io/alawael/`

لا أسرار ولا بيانات حقيقية في هذه الملفات. البيانات تُحفظ في متصفح الزائر فقط.
